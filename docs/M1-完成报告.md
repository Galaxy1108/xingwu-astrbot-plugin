## 6. 关键决策（与文档的差异）

1. **HTTP 层用插件内置 aiohttp 子应用**（文档 §3.1 方案），不用 Dashboard `register_web_api`
   （那是 `/api/plug/...` + Dashboard JWT，不适合终端用户 Cookie 会话）。
2. **数据模型补充**：`otp_codes`、`invites.code_hint`、`sessions.absolute_expires_at/csrf_token_hash`、
   `bots.snapshot`（模板快照）；`code_hash` 用 TEXT(hex)。
3. **CSRF**：双提交 Cookie + 会话内 hash 绑定；`__Host-sid` 在 http 调试时自动降级为 `sid`。
4. **扫码**：会话存内存（单进程），60s TTL、≤3 自动刷新、5min 空闲回收；finalize 会先补一次
   poll（客户端未轮询也能接入）；凭据 AES-256-GCM + AAD 后存 `bot_bindings`。
5. **记忆库**：M1 只做建库/删库/打开（SQLCipher），完整 CRUD/FTS/工具留给 M2（目录已按 §4.5.1 建好骨架）。
6. **降级**：无 SQLCipher 时显式报错/日志降级，绝不静默写明文库。
